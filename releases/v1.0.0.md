Glassboard's first self-hosted release: a simple shared whiteboard for a company workspace, with no accounts or external services.

- Touch and mouse drawing, zoom/pan, notes, text, shapes and arrows.
- Paste/drop/upload images and move or resize canvas objects.
- Undo/redo, PNG export and a searchable shared board library.
- Automatic saving and updates from other screens; independent object edits merge.
- Conflicting edits are preserved in a separate recovery board.
- Node.js server with no runtime dependencies; durable files on a persistent volume.
- Non-root Docker container and restart/persistence checks.

## Docker

The registry image supports **linux/amd64** and **linux/arm64**:

```sh
docker run -d --name glassboard --restart unless-stopped --init \
  -p 3000:3000 -v glassboard-data:/app/data \
  ghcr.io/progries/glassboard:1.0.0
```

Open `http://YOUR-SERVER-IP:3000`.

The downloadable Docker archive is **linux/amd64** only. Load it with:

```sh
gunzip -c glassboard-1.0.0-linux-amd64.docker.tar.gz | docker load
docker run -d --name glassboard --restart unless-stopped --init \
  -p 3000:3000 -v glassboard-data:/app/data glassboard:1.0.0
```

The source ZIP also includes Docker Compose and the setup guide. SHA256SUMS.txt verifies all release assets; container-digest.txt records the multi-platform registry digest.

Everyone who can reach the application can edit or delete all boards. Use your company LAN/VPN or existing access proxy. Run one instance per data directory. Realtime cursors/presence and automatic image garbage collection are not included.
