# Changelog

## 1.1.0 — 2026-10-13

Live WebSocket collaboration: incremental drawing, dragging and text previews, collaborator cursors and presence. Immediate committed-object pushes, smaller object-only save uploads, cached pen bounds, faster save debounce, reconnect/resync and polling fallback. Updated Docker image, locked `ws` dependency, Traefik configuration and upgrade guide. Existing stored boards require no migration.

## 1.0.0 — 2026-10-13

First self-hosted release. Shared account-free boards, glass-style desktop UI, touch/mouse drawing, image paste/upload, notes/shapes/text, zoom, undo/redo and PNG export. Persistent storage, concurrent object merging and conflict recovery. Docker deployment and automated release/image workflows.
